## 🌟 Visual Identity & Design Concept

- **Color Palette**: Deep space black (`#000000`), subtle charcoal glassmorphism, bright white primary typography, muted grey technical accents, and monochrome glows.
- **Atmosphere**: Deep celestial space environment featuring thousands of realistic multi-sized stars, cosmic dust particles, and an animated 3D celestial planet sphere with an orbital particle belt.
- **Typography**: Editorial layout combining **Syne** (bold architectural titles), **Plus Jakarta Sans** (clean modern body), and **JetBrains Mono** (technical data and metrics).
- **Interactions**:
  - Full-screen 3D starfield with mouse parallax and scroll-linked depth transitions.
  - Interactive 3D hero portrait card with tilt response and holographic data badges.
  - Full-screen lightbox modal for high-resolution certificate inspection.
  - Interactive project showcase linked to genuine GitHub repositories.
  - Sticky glassmorphism navigation with active section indicator and mobile drawer.

## 🚀 Running Locally & Deployment

### Local Preview
Simply open `index.html` in any modern web browser, or launch a local development server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js / npx
npx serve .
```

### GitHub Pages Deployment
1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete cinematic 3D portfolio"
   git push origin main
   ```
2. In your GitHub repository, navigate to **Settings** > **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set the branch to `main` and folder to `/(root)`, then click **Save**.
5. Your live portfolio will be hosted at `https://<your-username>.github.io/<repo-name>/`.
